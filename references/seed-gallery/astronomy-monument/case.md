# Astronomy / Monument Valley 种子创建 case · 2026-07-18

> **主题转向**:本 case 不是新主题,是**原 astronomy/(atlas dark,已移除)同主题的美术调性重做**。用户反馈"深色方向好,但美术调性要像纪念碑谷(柔和 / 几何 / 空灵),不是科学图表"。验证 B 解法对**同主题不同美术调性**的转向能力——同 RA/Dec / 星座 / 月 / 彗星 / 尺度梯,但走 Monument Valley + Escher + Calder 的柔和水彩几何,而非 Bayer + Hubble + Voyager 的科学观测档案。

## 诊断 · category-reflex 反向

- **impeccable category-reflex 默认路径**:天文 → 深色 + 星点 + 散点 + 数据面板(SIMBAD / NASA / HDF 套路)。**这是 slop 路径**:任何一个 LLM 看见"astronomy"都会做深空黑 + 白散点 + teal accent(template-02 dark-tech 换皮)。
- **本次走相反方向**:天文 → **柔和深紫渐变 + 等距几何块 + 空灵静谧**。不是科学图表,是几何梦幻。星体是悬浮的等距 cube / tetra / octa,不是散点;背景是 watercolor wash,不是星云照片;连线是 Ida 走过的 30° 金色路径,不是 constellation filament。
- **为什么必须反向**:同主题曾有三个种子(`astronomy/` 科学观测 / `astronomy-bright/` 羊皮古典 / `astronomy-nebula/` NASA 海报;前两个后已移除,现仅 nebula 与本 case 存留),第四个必须**美术调性截然不同**才能扩宽 case 库的设计空间。Monument Valley 是 user-supplied 的具体审美锚,不是模板默认。

## 审美意图先行(减法三件套)

### 一个具体情绪(不是泛"宇宙")

> **Ida 在寂静星空下走过几何星座路径,柔和渐变深紫底,星体是悬浮的等距几何块,空灵静谧**——纪念碑谷公主在埃舍尔式错觉空间里仰望。

不是"宇宙浩瀚"或"科学探索"。是**游戏操作者在不可能几何空间里**的具体感官:每一步都走在 30° 斜面上,星体是可以触摸的悬浮 monolith,背景是水彩 wash 而不是数据。

### 一个签名时刻

**"Plate Pillar · Plate I-VIII"** — 每页右侧的垂直罗马编号 totem,8 页连成一个序列。这是 Monument Valley totem pillar 的形式(ustwo 游戏 The Vault / The Citadel 关卡里的 monolith),不是 metadata。它**贯穿 8/8 页**,去色后仍是"垂直序列标号",立刻识别为 atlas 而非散页 deck。

### 一个极端对比

**Soft watercolor wash vs hard isometric geometry**:背景是 6 阶段柔和渐变(night-deep → night-mid → night-soft → blush / mist),前景是 hard-edge 等距 cube / tetra / octa / prism。同色系(深紫家族)但相反质感——这是 Monument Valley 的视觉语法:**柔和水彩承载硬边几何**。

## 外部大师参考(禁读 examples/template-*.html)

调研 6 个 Monument Valley / 几何梦幻 / 错觉空间来源,**不抄元素,内化为什么美**:

1. **Monument Valley (ustwo games, 2014)** — 等距几何 + 柔和马卡龙渐变 + Ida 公主走过不可能空间。
   - **为什么美**:颜色低饱和(深紫 / 深蓝 / 柔粉 / 薄荷)+ 几何极简(cube / 柱 / 阶梯)+ 错觉空间(Escher 转角)。每一帧都是**静态构图**而非动态场景——这与天文 atlas 的"plate-by-plate"页面节奏天然对齐。本 deck 的 cover 金色 cube + Ida 走 30° 路径 + 柔和紫渐变是 ustwo title page 的直接致敬。
2. **M.C. Escher "Relativity" (1953) / "Ascending and Descending" (1960)** — 不可能空间 / Penrose 阶梯。
   - **为什么美**:Escher 把**错觉**作为内容本身——观者无法决定哪个方向是"上"。本 deck Plate VII 的 stair-without-top(5 阶 + 2 ghost + dashed loop-back path)直接重演 Penrose 阶梯,每阶放一颗 shrinking star-solid,把"宇宙尺度无穷"翻译成"永远走不到顶的几何阶梯"。
3. **Alexander Calder "Universe" (1934) / Cosmic Mobiles** — 悬浮几何平衡系统。
   - **为什么美**:Calder mobile 是**动态平衡**——每个 solid counter-weight 其他所有。本 deck Plate V 的 five wanderers(水星 tetra / 金星 cube / 火星 cube / 木星 octa / 土星 cube+ring)从一根 anchor 丝线挂下,横杆在中心 balance,这是 Calder 1934 "Universe" 雕塑的直接引用——行星不是 orbit,是 counterweighted mobile。
4. **Saul Bass (1950s-60s) geometric film posters** — 单一几何形 + 限量色 + 大字。
   - **为什么美**:Bass 把电影海报减到**一个形状 + 一种颜色 + 一个字**。本 deck 的 cover(单一 cube + Ida + Atlas 标题)是 Bass 语法:每一页只有一个 geometric solid + 2-3 行 Tenor Sans + 一段 italic body。完全没有 chart-junk。
5. **Voyager Golden Record cover (1977)** — 几何宇宙符号 + 极简图示。
   - **为什么美**:Voyager cover 是**给外星文明的几何密码**——pulse diagram / solar system position / hydrogen transition。本 deck Plate VI 的 comet(tetra head + watercolor tail + dashed orbit)和 Plate VII 的 cosmic ladder(10⁰ → 10²⁶ m 5 阶)借鉴这种"几何符号承载物理意义"——但用 Monument Valley 的水彩柔和而非 Sagan 团队的硬线工程图。
6. **Studio Ghibli 夜空 (Kaguya-hime / Spirited Away / Howl)** — 柔和梦幻手绘星空。
   - **为什么美**:Ghibli 夜空不是黑底白点,是**深蓝紫渐变 + 柔光月晕 + 水彩雾**。本 deck 的 `--c-night-deep: #2D1B4E`(深紫,非纯黑)+ `--c-cream: #F5E8D0`(暖月光,非纯白)+ 每页 moon-glow radial wash 是 Ghibli Kaguya "夜祭" 那场色调的直接借鉴。

**严禁参考的来源**:Hubble / JWST 照片(走 astronomy-nebula 路径)、NASA mission control dashboard(template-02 dark-tech 路径)、Tailwind "space gradient hero"(AI slop 来源)、Dribbble "galaxy poster"(generic)。

## 审美推导"为什么美"(不只列元素)

### 为什么"柔和深紫渐变 + 硬边几何"传达空灵静谧

不是"颜色好看"。是**明度对比低 + 形状对比高**——背景所有颜色在 CIELAB L*=20-60 区间(柔和中低调),前景几何用 stroke + soft glow 而非 hard shadow。眼睛没有"看哪里"的强迫,可以游走——这是 Monument Valley 操作者感受的核心:**不被视觉噪音驱赶,可以停下来看**。Slide 1 cover 的 cube 在 cream moon-glow 里浮起,既不刺眼也不消失,这种"被照亮但不灼眼"的临界状态就是空灵。

### 为什么"等距 30° 块 + Ida 走 path"传达可走星空

不是"立体感"。是**游戏 affordance**——Monument Valley 操作者知道"30° 斜面是可以走的,cube 是可以爬的"。把星座连线画成 30° 折线(Slide 3 Orion)+ Ida 在 path 起点(Slide 1 / 2 / 4 / 7 / 8 公主小图标)+ path 走向 cube(每个 star-solid 是可达目的地),整个 deck 变成**可走的几何空间**,而非**只能看的天文图表**。这是 uswo 游戏语法对天文 atlas 的翻译。

### 为什么"限量 4 色水彩"比"堆色"更梦幻

不是"颜色少好看"。是**柔和色域内的高频变化**——本 deck 主色仅 4 个(night-deep 紫 / cream 月光 / gold 路径 / mist 远雾)+ 2 个派生(night-mid / night-soft)+ 1 个 spot(blush 红巨星)。Saturation 全部低(0.05-0.20)。但通过渐变阶段(每页 3 段 linear-gradient)+ radial moon-glow 位置变化,8 页彼此区分。这是 SSG(Shibumi / Settei / Ghibli)的色彩哲学:**色域窄 → 情绪统一 → 梦幻感来自渐变而非色种**。

## CSS 工艺关键决策(防回归)

### Specificity 陷阱(本次修复的 root cause)

初始版本有一条全局 override:
```css
.reveal section > *:not(.sky-wash):not(.moon-glow):not(.composition):not(.plate-pillar) {
  position: relative; z-index: 3;
}
```
特异性 = (0,4,1) = 41,**高于所有 layout rule**(如 `.stair .ladder-rungs { position: absolute }` 特异性 20)。后果:所有 `position: absolute` 声明被静默覆盖为 `relative`,导致 plate-content / ladder-rungs / tail-note / cover-foot 全部回到 normal flow,出现 58 处 viewport 溢出。

修复方案:整个 selector 包 `:where()`(特异性归零):
```css
:where(.reveal section > *:not(.sky-wash):not(.moon-glow):not(.composition):not(.plate-pillar)) {
  position: relative; z-index: 3;
}
```
现在 specificity = 0,任何 `.slide .child { position: absolute }` 都能 win。

**教训**:在写全局 override 时,**必须计算 specificity vs layout rule**。**:where() 不是糖,是防御性工艺**。

### 用 `top:Ypx` 而非 `bottom:Ypx`

`position: absolute; bottom: Y` 配合 auto-height 内容,dynamic height 计算会向上推 top 位置。当内容比预期高(字体回退 / 长文案 / unicode metrics 偏差),top 会越界进入负数。

修复:对所有可能 dynamic grow 的 text column,优先 `top: 56px` 锚定,top 永不越界。
