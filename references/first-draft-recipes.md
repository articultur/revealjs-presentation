# 首稿配方速查

> 从 10 套种子模板与历代复盘案例得到的常见内容 → 推荐布局映射。先按配方落地，再根据 lint/validate 反馈调整，比"自由发挥后再修"省 2-3 轮迭代。
>
> 布局命名对齐 `layout-archetypes.md` 的 A1-A12 archetype 体系与 `design-polish.md` 的页面类型 / 签名时刻配方；通用容器（代码块、基础网格、流程图骨架）查 `layout-patterns.md`，密度硬上限与溢出决策查 `content-budget.md`。

## 映射总表

| 内容类型 | 推荐布局 | 一句关键约束 |
|---------|---------|-------------|
| 封面 | A1 Masthead Cover | 标题报头尺度（2.8em+），侧栏事实 ≤5 行 |
| 单一主张 / 章节分隔 | A2 Manifesto Statement（或配方 4 全出血色块） | 命题一句话，留白 ≥40%，不加卡片容器 |
| 单个核心数字 | A5 Anchor Numeral（或配方 3 单数字聚焦） | 锚点 ≥4em，配证据列 + 来源标注 |
| 3-4 个 KPI | A7 KPI Grid | 数字 ≥2.5em，>4 拆页，至多 1 张反相 |
| 4-6 项列表 | 编号标签列表（01 + 主张 ── 一行解释） | 每项 ~1.5em，7+ 项拆页或转分组卡 |
| 3 条结论 / takeaway | A11 Takeaway Roster | 顶边卡 ≤3 张，序号 i/ii/iii ≥2em |
| 时间线 4-6 节点 | A3 Register Axis | 节点 ≤6，每节点 年份 + h4 + 1 行说明 |
| 两值 / 两方案对比 | A6 Face-Off Compare | 禁 50:50，必须给比率裁决 |
| 前后优化 / 机制 | A8 Mechanism Diagram | 条数 3-5，后栏 accent 高亮量化收益 |
| 多列数据表 | A9 Evidence Table | 列 ≤5、行 ≤6，主角列 accent 高亮 |
| 引用 / 第三方背书 | A10 Pullquote（或配方 1 超大引言） | 引言 ≤3 行，serif italic，给出处 |
| 收尾页 | A12 Masthead Closing | 呼应封面报头，禁"Thank You"空页 |
| 路演 CTA 收尾 | 实色 CTA + 二级按钮 + colophon | 按钮用实色块，不用 ghost button |

## KPI / 数字看板

| 适用内容 | 推荐布局 | 参数与约束 |
|---------|---------|-----------|
| 3-4 个 KPI 指标 | A7 KPI Grid（2×2 或 1×4 粗边框卡）+ 趋势 delta | 卡片 padding `1.2em 1.4em`，数字 ≥2.5em（推荐 2.7-3em 斜体），趋势 ▲/▼ + accent 色；1 张反相做重点 |
| **5+ 个 KPI 指标** | **拆 2 页**（4+N 或 N+N） | 不要硬塞，违反内容预算（`content-budget.md` 密度上限） |
| 单个震撼数字 | A5 Anchor Numeral / 配方 3 单数字聚焦 | 数字 4-5em+ 做引力中心，旁列证据/基准，加 source 行 |
| 任何数字 + 来源 | 布局不变，数字旁加 Evidence Ledger 标签 | `verified / user-provided / illustrative` 三选一，失败门禁 #3 要求；无可靠来源改趋势/区间表达或标"示意" |

## 列表 / 要点

| 适用内容 | 推荐布局 | 参数与约束 |
|---------|---------|-----------|
| 4-6 项进展/特性列表 | 编号 01-NN + em-dash 解释（`design-polish.md` 编号标签样式） | `01 + 4-6 字主张 + ── + 一行解释`，每项 ~1.5em；kicker 类 label 记得 `align-self:flex-start`（flex label 收缩陷阱） |
| 7+ 项列表 | 拆 2 页或转为 2×2 分组卡 | 超出密度上限即拆页，不靠缩字号硬塞 |
| 3 条启示/结论 | A11 Takeaway Roster | 顶部 3px accent 边 + 巨型罗马序号 + 标题 + 一行说明，卡数 ≤3 |

## 时间线 / 历程

| 适用内容 | 推荐布局 | 参数与约束 |
|---------|---------|-----------|
| 时间线 4-6 节点总览 | A3 Register Axis 横向时间轴 | 横轴等距节点圆点，节点上方年份、下方一句话；重点节点 accent，其余 muted |
| 长编年 / 多事件 | A4 满版分割 × 时间线，或逐页 A5 锚点日期 | 每页 1 个事件锚点 + 证据列；A4 当节奏锚，每 2-3 页出现一次 |
| 路线图 / 里程碑 | A3 变体（当前节点 accent 高亮） | 节点 >6 拆页；不要全部节点都 accent（无主次） |

## 对比

| 适用内容 | 推荐布局 | 参数与约束 |
|---------|---------|-----------|
| 两值对峙（价格/新旧/方案 A-B） | A6 Face-Off Compare | 52:48 非对称，一侧满版色块；裁决数字 ≥2em，无裁决 = 对峙没结论 |
| 前后优化对比 | A8 Mechanism Diagram | 前→后条状量化（"减少 N%"），后栏 accent 满版高亮 |
| 多方案 / 多产品矩阵 | A9 Evidence Table | 主角列高亮；列 >5 砍列，行 >6 拆页 |

## 流程 / 机制

| 适用内容 | 推荐布局 | 参数与约束 |
|---------|---------|-----------|
| ≤5 步线性流程 | `layout-patterns.md` 流程图布局（横排步骤） | >5 步拆成两行；节点用 grid/flex 承载 |
| 转换 / 压缩 / 优化证明 | A8 Mechanism Diagram | 条数 3-5，中间 →，量化"省了多少"；不用 Mermaid 抽象节点图 |
| 复杂系统流程 | `design-polish.md` Template 13 system-flow 语法 | 必须显示责任边界、异常路径和恢复策略 |

## 引用 / 背书

| 适用内容 | 推荐布局 | 参数与约束 |
|---------|---------|-----------|
| 第三方金句 / 背书 | A10 Pullquote | 上下双线 + 巨型斜体引言（~1.85em）+ 左侧 meta 栏（编号/人名/职位）；引言 ≤3 行 |

## 通用规则

- **拆页优先**：心算高度 > 14em 即拆（`content-budget.md` 溢出决策树：①拆页 → ②缩文案 → ③改 proof object → ④缩字号，最后才缩字号）。
- **节奏**：主骨架 ≥3 种 archetype 且 ≥1 种为本主题发明的变体（失败门禁 #9 换皮）；连续 2 页相同 archetype = 失败；A4 满版分割做节奏锚，A2/A10 当呼吸页插在密集数据页之间。
- **每页 1 个视觉重心**：一句金句、一个大数字、一张图、或一个对比，不要什么都强调。
- 骨架代码与反模式清单见 `layout-archetypes.md` 各 archetype 小节。
